A new project, and every project of a database that installs the module,
is Standard: nothing changes until a project is switched.

**Make a project Public or Private**

As a Project Administrator, on the project form:

#. *Settings* tab: set **Access** to Public or Private. The Visibility, the
   Team Members and the share button are hidden, and the *Members* tab
   appears. The *Share* entry of the gear menu stays and is refused.
#. *Members* tab: add the users with their role, at least one Admin, and
   save. A Project Administrator names the first Admins of the project; from
   then on only its Admins and Settings administrators change its members,
   its Access and its other settings.
#. For a Private project, add every assignee and UAT user of its tasks as a
   member first: only members are set on its tasks afterwards, and only
   members read it.
#. Give the project stages of its own: a stage it shares with a Standard
   project is changed only by a Project Administrator who is an Admin of
   one of the Public or Private projects the stage belongs to.

The project form and the stages are saved with Project / Administrator
rights: an Admin who keeps the members or the stages needs them too. The
project that develops this Odoo cannot be Private.

**Back to Standard**

An Admin sets **Access** to Standard: the Visibility decides again, and the
members stay on the project, hidden, acting on nothing.
