Shows the announcement of new release notes (``release_notes``) in the apps
menu of ``web_responsive``: the panel at the top of the menu and the counter
on its icon. ``web_responsive`` replaces Odoo's apps menu, where
``release_notes`` places them otherwise.

Installed automatically when both modules are installed together. On a
database that has both already, install it by hand, or let the project's
holder module depend on it.
