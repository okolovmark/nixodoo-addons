Press **Timelog** in the header:

* with no timer running, press the play button of a task to start one, or
  the task to open it; where Odoo logs your time only for a follower and
  you no longer follow the task, the start makes you follow it again;
* with a timer running, press *Stop* to end its timesheet line, or the task
  to open it where you can read it (else its name shows as plain text).

*Start work* on a task form follows the task again the same way.
